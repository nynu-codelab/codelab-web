## 🔴 P0：上线阻碍（必须在上线前修复）

### 1. 用户管理后端 API 完全缺失

- **对应需求**：7.3 用户管理
- **现状**：后端无任何管理员用户管理端点（用户列表、按用户名/手机号搜索、查看详情、禁用/启用、修改角色、重置密码均未实现）。
- **前端表现**：`admin-web/src/views/UsersView.vue` 显式标注"用户管理接口尚未实现，当前保留占位表格，不接入虚假数据"。
- **上线影响**：管理员无法管理注册用户，无法禁用恶意账号、无法重置密码。

### 2. 登出接口未实现 ✅ 已修复（阶段 2）

- **对应需求**：10.1 认证接口（`POST /api/auth/logout`）
- **修复内容**：后端已实现 `POST /api/auth/logout`，登出时将当前 token 加入内存黑名单，后续使用原 token 访问受保护接口返回 401。前台 web 和后台 admin-web 的退出登录均已接真实接口。
- **遗留风险**：黑名单为内存实现，服务重启后丢失；多实例不共享。生产建议切换 Redis。

### 3. 修改密码接口未实现 ✅ 已修复（阶段 2）

- **对应需求**：5.11 个人中心（修改密码功能）、10.1（`POST /api/auth/change-password`）
- **修复内容**：后端已实现 `POST /api/auth/change-password`，校验旧密码/新密码一致/长度≥6，BCrypt 更新后强制当前 token 失效。前台 web 个人中心新增修改密码弹层，后台 admin-web 用户下拉菜单新增修改密码入口。修改成功后均跳转登录页。

### 4. 成员管理后端 API 完全缺失

- **对应需求**：7.7 成员管理、9.6 `lab_member` 表
- **现状**：后端无成员 CRUD 端点。`admin-web/src/views/MembersView.vue` 是占位页（"暂未接入成员管理接口"）。`web/src/views/MembersView.vue` 自述"成员展示模块后续将对接真实成员数据。当前正式页仅展示团队能力结构，不编造真实成员姓名、头像或联系方式"。
- **前端表现**：前台成员页展示 3 个角色能力结构（BE/FE/OPS），而非真实成员信息。
- **上线影响**：核心成员展示功能完全缺失。

### 5. 技术方向管理后端 API 完全缺失

- **对应需求**：7.8 技术方向管理、9.7 `lab_direction` 表
- **现状**：后端无方向 CRUD 端点。`admin-web/src/views/DirectionsView.vue` 是占位页（"暂未接入方向管理接口"）。前台 `DirectionsView.vue` 和 `HomeView.vue` 中的方向数据均为硬编码静态数组。
- **上线影响**：技术方向内容无法在后台动态维护，任何修改都需要改前端代码重新部署。

### 6. 站点配置后端 API 完全缺失

- **对应需求**：7.9 站点配置、9.8 `lab_site_config` 表
- **现状**：后端无站点配置端点。`admin-web/src/views/SiteView.vue` 是占位页（"站点配置接口尚未实现"）。
- **上线影响**：网站名称、首页标语、联系方式、页脚声明、二维码等所有站点级配置无法在后台修改。

### 7. 文件上传后端 API 完全缺失

- **对应需求**：7.10 文件上传、10.10（`POST /api/admin/upload`）
- **现状**：后端 `application.yml` 配置了 multipart（max 10MB），但无任何文件上传 Controller。`admin-web/src/views/UploadView.vue` 是占位页（"文件上传模块尚未实现，当前不提供本地上传入口"）。文章封面、项目封面等 `coverUrl` 字段只能手动填入外部 URL。
- **上线影响**：管理员无法通过后台上传图片，所有媒体资源依赖外部链接。

### 8. 联系我们页面是纯占位

- **对应需求**：5.13 联系我们
- **现状**：`web/src/views/ContactView.vue` 文案自述"当前站点未配置公开联系方式字段。为了避免伪造真实联系方式，本页提供可用的站内路径和后续配置说明"。页面无实际联系方式、无二维码、无地点信息，只有跳转到报名/介绍的链接按钮。
- **上线影响**：访客无法获取实验室联系信息，页面形同虚设。

## 🟡 P1：高优先级（应在首次上线前完成）

### 9. 数据概览统计 API 缺失

- **对应需求**：7.2 数据概览
- **现状**：`admin-web/src/views/DashboardView.vue` 显式标注"当前统计接口尚未实现，因此保持占位，不编造注册人数、报名人数或内容数量"。所有统计卡片显示 `-`。
- **建议**：至少实现注册用户数、报名人数、待审核人数、文章数量、项目数量 5 个基础统计。

### 10. `lab_article_category` 和 `lab_article_tag` 表已创建，尚未与文章表关联

- **对应需求**：9.4、9.5
- **现状**：这两张表已在阶段 1 创建完成并初始化种子数据（4 个分类、6 个标签），但尚未提供独立管理接口或与 `lab_article` 表的关联查询。
- **影响**：分类和标签数据已有字典，但文章仍使用自由文本字段。

### 11. `lab_member`、`lab_direction`、`lab_site_config`、`lab_upload_file` 表已创建，后端 API 尚未实现

- **对应需求**：9.6、9.7、9.8、9.9
- **现状**：这 4 张表已在阶段 1 创建完成（`deploy/mysql/init/01-init.sql`），但对应的后端 CRUD API 和后台管理页面仍为占位状态。
- **影响**：P0 中 #4-#7 的表依赖已解决，需继续实现后端 API。

### 12. 前台技术方向页使用硬编码数据

- **对应需求**：5.4 技术方向（需从后端动态加载）
- **现状**：`DirectionsView.vue` 和 `HomeView.vue` 中 5 个方向的名称、简介、标签全部硬编码在 `<script setup>` 中。
- **影响**：后台即使后续实现方向管理，前台也无法联动。需先实现后端 API，再改造前台为动态获取。

### 13. 前台关于页全部静态内容

- **对应需求**：5.3 实验室介绍（建议通过后台可维护）
- **现状**：`AboutView.vue` 中实验室介绍、培养目标、学习方式等内容全部硬编码。
- **影响**：实验室定位等信息变更需要改前端代码。

## 🟠 P2：中优先级（影响体验和运维，建议尽快补齐）

### 14. 无分页功能

- **对应需求**：文章列表、项目列表
- **现状**：所有公开列表接口（`GET /api/articles`、`GET /api/projects`、`GET /api/admin/applications` 等）全量返回，无分页参数。内容量增长后性能和体验会显著下降。

### 15. 无后台搜索功能

- **对应需求**：7.3（按用户名/手机号搜索用户）、7.4（按状态/方向筛选报名）
- **现状**：报名管理已有状态筛选参数，但用户管理整个模块缺失，文章/项目管理无搜索。

### 16. 无登录限流 ✅ 已修复（阶段 2）

- **对应需求**：12.1 账号安全（"登录接口需要基础限流"）
- **修复内容**：已实现 `LoginAttemptService` / `InMemoryLoginAttemptService`，按 IP + username 组合记录失败次数。连续失败 5 次后锁定 10 分钟，成功登录后清理计数。错误信息统一返回"用户名或密码错误"，不区分用户是否存在。
- **遗留风险**：内存实现，服务重启后计数丢失；多实例不共享。生产建议切换 Redis + 滑动窗口算法。

### 17. 无单元测试

- **对应需求**：质量保障
- **现状**：后端 `pom.xml` 包含 `spring-boot-starter-test`，但 `src/test` 目录不存在，零测试覆盖。

### 18. Markdown 渲染无目录导航（TOC）

- **对应需求**：5.7 文章详情（"目录导航，可选"）
- **现状**：`markdown-it` 渲染无 TOC 插件，长文章阅读体验受限。
- **说明**：需求标注为可选，非阻塞项。
