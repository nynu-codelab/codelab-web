# 生产部署环境变量模板

> 日期：2026-06-22
> 用途：生产环境 `deploy/.env` 完整环境变量参考
>
> **本文件不包含真实密码、密钥或证书。** 所有敏感值使用 `CHANGE_ME_*` 占位符。
> 实际部署时，从此模板复制到 `deploy/.env` 并替换所有占位符。
>
> **`deploy/.env` 已被 `.gitignore` 忽略，禁止提交到 Git。**

---

## 一、完整环境变量清单

将以下内容保存为 `deploy/.env`，逐项替换 `CHANGE_ME_*` 占位符。

```bash
# ============================================================
# NYNU Code Lab 生产环境变量
# 复制方式：cp deploy/.env.example deploy/.env
# 所有 CHANGE_ME_* 占位符必须替换为真实值
# ============================================================
# ⚠️  本文件已在 .gitignore 中排除，禁止提交到 Git
# ⚠️  生产环境必须使用强随机密码和密钥
# ============================================================

# --- Spring 配置 ---
SPRING_PROFILES_ACTIVE=docker
SERVER_PORT=8080
BACKEND_PORT=8080

# --- MySQL ---
MYSQL_ROOT_PASSWORD=CHANGE_ME_STRONG_ROOT_PASSWORD_AT_LEAST_16_CHARS
MYSQL_DATABASE=nynu_code_lab
MYSQL_USER=nynu
MYSQL_PASSWORD=CHANGE_ME_STRONG_USER_PASSWORD_AT_LEAST_16_CHARS
MYSQL_PORT=3306

# --- Redis ---
REDIS_PORT=6379
REDIS_PASSWORD=CHANGE_ME_STRONG_REDIS_PASSWORD
REDIS_DATABASE=0

# --- JWT ---
# 生成方式：openssl rand -base64 64
JWT_SECRET=CHANGE_ME_64_CHARS_RANDOM_BASE64_JWT_SECRET

# --- Nginx ---
NGINX_PORT=80

# --- 文件上传 ---
UPLOAD_BASE_PATH=/app/uploads
```

## 二、变量详细说明

### 2.1 Spring 配置

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `SPRING_PROFILES_ACTIVE` | `docker` | **不可修改。** 激活 Docker profile，使用容器内服务名连接中间件 |
| `SERVER_PORT` | `8080` | 后端容器内端口。**不建议修改**，Nginx upstream 硬编码 `backend:8080` |
| `BACKEND_PORT` | `8080` | 后端宿主机映射端口。如需改变外部端口，修改此变量即可 |

### 2.2 MySQL

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `MYSQL_ROOT_PASSWORD` | **必须替换** | MySQL root 密码，至少 16 位，含大小写字母、数字、特殊字符 |
| `MYSQL_DATABASE` | `nynu_code_lab` | 数据库名，保持默认即可 |
| `MYSQL_USER` | `nynu` | 应用连接数据库的用户名 |
| `MYSQL_PASSWORD` | **必须替换** | 应用连接数据库的密码，至少 16 位 |
| `MYSQL_PORT` | `3306` | MySQL 宿主机端口。如宿主机已有 MySQL，改为其他端口如 `33066` |

> **注意：** `MYSQL_HOST` 在 `docker-compose.yml` 中硬编码为容器服务名 `mysql`，无需在 `.env` 中配置。
> 如使用外部数据库，需修改 `docker-compose.yml` 中 backend 服务的 `MYSQL_HOST` 环境变量。

### 2.3 Redis

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `REDIS_PORT` | `6379` | Redis 宿主机端口 |
| `REDIS_PASSWORD` | **建议设置** | Redis 密码。当前 `.env.example` 中为空，生产环境建议设置强密码 |
| `REDIS_DATABASE` | `0` | Redis 数据库编号，保持默认即可 |

> **注意：** `REDIS_HOST` 在 `docker-compose.yml` 中硬编码为容器服务名 `redis`，无需在 `.env` 中配置。
> `AUTH_REDIS_ENABLED` 在 Docker profile 下硬编码为 `"true"`，无需在 `.env` 中配置。

### 2.4 JWT

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `JWT_SECRET` | **必须替换** | JWT 签名密钥。使用 `openssl rand -base64 64` 生成 |

相关 Sa-Token 配置（在 `application.yml` 中，非环境变量）：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `sa-token.token-name` | `Authorization` | Token 在 HTTP 头中的名称 |
| `sa-token.timeout` | `604800`（7 天） | Token 有效期（秒） |
| `sa-token.token-style` | `tik` | Token 风格 |
| `sa-token.token-prefix` | `Bearer` | 前端请求头前缀格式 |
| `sa-token.jwt-secret-key` | `${JWT_SECRET:...}` | JWT 密钥，从环境变量注入 |

### 2.5 Nginx

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `NGINX_PORT` | `80`（HTTP）/ `443`（HTTPS） | Nginx 宿主机映射端口。生产环境建议 443 |

> 如果生产启用 HTTPS，Nginx 443 端口需在 `docker-compose.yml` 中增加 `- "443:443"` 端口映射。

### 2.6 文件上传

| 变量 | 生产值 | 说明 |
|------|--------|------|
| `UPLOAD_BASE_PATH` | `/app/uploads` | 容器内上传文件存储路径。**不建议修改**，与 Docker volume 挂载路径绑定 |

相关配置（在 `application.yml` 中，非环境变量）：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `app.upload.url-prefix` | `/uploads` | 文件对外访问 URL 前缀 |
| `spring.servlet.multipart.max-file-size` | `10MB` | 单文件最大大小 |
| `spring.servlet.multipart.max-request-size` | `10MB` | 单次请求最大大小 |

### 2.7 前端 API 地址

当前前后端通过 Nginx 统一托管在同域下，前端 API 地址硬编码为相对路径：

| 前端 | API 基地址 | 配置文件 |
|------|-----------|----------|
| 前台 web | `/api` | `web/src/api/request.ts` 中 `baseURL: '/api'` |
| 后台 admin-web | `/api` | 由 `admin-web/vite.config.ts` 中 `base: "/admin/"` 控制，API 使用相对路径 |

> 如前后端分离部署（不同域名），需在构建前设置环境变量或修改 `request.ts` 中的 `baseURL`。

## 三、生产环境必须替换项

以下项目在部署前**必须**替换，不可使用默认值或占位符：

| # | 变量 | 当前占位符 | 替换方式 |
|---|------|-----------|----------|
| 1 | `MYSQL_ROOT_PASSWORD` | `CHANGE_ME_STRONG_ROOT_PASSWORD_AT_LEAST_16_CHARS` | `openssl rand -base64 24` |
| 2 | `MYSQL_PASSWORD` | `CHANGE_ME_STRONG_USER_PASSWORD_AT_LEAST_16_CHARS` | `openssl rand -base64 20` |
| 3 | `REDIS_PASSWORD` | `CHANGE_ME_STRONG_REDIS_PASSWORD` | `openssl rand -base64 20` |
| 4 | `JWT_SECRET` | `CHANGE_ME_64_CHARS_RANDOM_BASE64_JWT_SECRET` | `openssl rand -base64 64` |

### 一键生成命令

```bash
echo "MYSQL_ROOT_PASSWORD=$(openssl rand -base64 24)"
echo "MYSQL_PASSWORD=$(openssl rand -base64 20)"
echo "REDIS_PASSWORD=$(openssl rand -base64 20)"
echo "JWT_SECRET=$(openssl rand -base64 64)"
```

### 管理员密码

默认管理员账号 `admin` / `admin123` 通过 BCrypt 存储在数据库中。**首次登录后必须立即修改密码：**
- 前台：登录后进入个人中心 → 修改密码
- 后台：登录后点击右上角用户下拉菜单 → 修改密码

## 四、不提交 Git 的文件清单

以下文件**绝对不能**提交到 Git：

| 文件 | 原因 | gitignore 状态 |
|------|------|---------------|
| `deploy/.env` | 含数据库密码、JWT 密钥 | ✅ `.gitignore:33` |
| `.env` | 可能含敏感信息 | ✅ `.gitignore:32` |
| `*.pem`、`*.key`、`*.crt` | HTTPS 证书和私钥 | 需确认 .gitignore 已覆盖 |
| `*.sql.gz`、`*.sql`（备份） | 数据库备份含用户数据 | 不应出现在仓库目录 |
| `data/` 目录 | 持久化数据 | 不应出现在仓库目录 |
| `backup/` 目录 | 备份文件 | 不应出现在仓库目录 |

### 验证命令

```bash
# 确认 .env 未被 Git 跟踪
git ls-files .env deploy/.env
# 预期：空输出（无跟踪）

# 确认 .env 被 .gitignore 忽略
git check-ignore -v .env deploy/.env
# 预期：显示 .gitignore 行号

# 扫描是否有证书/私钥文件
find . -name "*.pem" -o -name "*.key" -o -name "*.crt" 2>/dev/null
# 预期：空输出
```

## 五、Docker Compose 中的硬编码说明

以下配置在 `docker-compose.yml` 中硬编码，不通过 `.env` 控制：

| 配置项 | 硬编码值 | 原因 |
|--------|----------|------|
| `SERVER_PORT` | `8080` | Nginx upstream 硬编码 `backend:8080`，需同步修改 |
| `MYSQL_HOST` | `mysql` | Docker Compose 服务名 |
| `REDIS_HOST` | `redis` | Docker Compose 服务名 |
| `AUTH_REDIS_ENABLED` | `"true"` | Docker 环境始终启用 Redis |
| `UPLOAD_BASE_PATH` | `/app/uploads` | 容器内固定路径，与 volume 挂载绑定 |
| `MYSQL_PORT`（容器内） | `3306` | 容器内固定端口 |
| `REDIS_PORT`（容器内） | `6379` | 容器内固定端口 |

如需修改上述值，需同时修改 `docker-compose.yml` 和 `deploy/nginx/nginx.conf`（如涉及）。
