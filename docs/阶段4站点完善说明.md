## 5. 配置变更

`backend/src/main/resources/application.yml` 新增 `app.upload` 配置段：

```yaml
app:
  upload:
    base-path: ${UPLOAD_BASE_PATH:uploads}
    url-prefix: /uploads
```

- `base-path`：文件存储根目录，默认为 `uploads`（相对于应用工作目录），生产环境通过 `UPLOAD_BASE_PATH` 环境变量覆盖。
- `url-prefix`：上传文件对外访问的 URL 前缀，由 Nginx 映射到 `base-path` 目录。

## 8. 招新状态流转

新增两个中间状态，使审核流程更细化：

```
PENDING → VIEWED → CONTACTED → PRELIMINARY_PASSED → INTERVIEWING → PASSED
                              ↘ REJECTED
```

旧状态枚举（6 个）：`PENDING`、`PRELIMINARY_PASSED`、`INTERVIEWING`、`PASSED`、`REJECTED`、`WITHDRAWN`

新状态枚举（8 个）：`PENDING`、`VIEWED`、`CONTACTED`、`PRELIMINARY_PASSED`、`INTERVIEWING`、`PASSED`、`REJECTED`、`WITHDRAWN`

变更位置：
- `ApplyRecord.java` 新增 `STATUS_VIEWED` 和 `STATUS_CONTACTED` 常量
- `ApplyRecordServiceImpl` 审核状态机更新，支持从 PENDING → VIEWED、VIEWED → CONTACTED 等流转
- `AdminApplyController` 审核接口 `PUT /api/admin/applications/{id}/review` 支持新状态值
- 数据库 `lab_apply_record.status` 列 COMMENT 已更新包含全部 8 个状态

## 9. 数据库变更

- `lab_site_config` 种子数据新增 `recruitOpen` 配置项（默认值 `true`，控制招新表单是否对访客可见）
- `lab_apply_record.status` 列 COMMENT 从 6 个状态更新为 8 个状态（新增 VIEWED、CONTACTED）
- 以上变更已合并到 `deploy/mysql/init/01-init.sql`
