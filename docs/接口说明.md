# NYNU Code Lab — 接口说明

## 1. 接口规范

### 1.1 接口前缀

所有 API 以 `/api` 为前缀。本地开发时后端运行在 `http://localhost:8080`，Docker 部署时通过 Nginx 统一代理到同域 `/api`。

### 1.2 认证方式

使用 Sa-Token JWT 模式。登录成功后返回 Token，后续请求在 `Authorization` 请求头中携带：

```
Authorization: Bearer <token>
```

- Token 有效期：7 天
- 登出后 Token 加入黑名单（Redis/SHA-256 摘要存储），立即失效
- 前端请求拦截器自动附加 Token，响应拦截器统一处理 401

### 1.3 通用响应格式

所有接口使用 `Result<T>` 统一封装：

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

### 1.4 分页格式

列表接口统一使用 `PageResult<T>`：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [ ... ],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

分页参数：`page`（默认 1）、`pageSize`（默认 10）。

### 1.5 错误码约定

| 业务码 | 含义 |
|--------|------|
| `200` | 成功 |
| `400` | 请求参数错误 |
| `401` | 未登录或登录已过期（token 无效/已登出） |
| `403` | 角色权限不足（非 ADMIN 访问管理接口） |
| `500` | 服务器内部错误 |

## 4. 权限路径排除

以下路径在 `SaTokenConfig` 中排除鉴权，游客可直接访问：

```
/api/auth/register
/api/auth/login
/api/health
/api/site-config/**
/api/members/**
/api/directions/**
/api/articles/**
/api/projects/**
```

其余 `/api/admin/**` 路径需要 ADMIN 角色，`/api/applications/**` 需要登录。

## 5. 前端 API 配置

前后端通过 Nginx 统一托管在同域下，前端 API 基地址为相对路径 `/api`：

| 前端 | 配置文件 | 基地址 |
|------|----------|--------|
| 前台 web | `web/src/api/request.ts` | `/api` |
| 后台 admin-web | `admin-web/src/api/request.ts` | `/api` |

如前后端分离部署（不同域名），需修改 `request.ts` 中的 `baseURL` 为完整 URL。
